# Русификатор Groundwork Simulator

Полный ручной перевод Groundwork Simulator на русский язык вместо встроенного машинного.

Встроенный русский перевод в игре сделан машинно: "Старый Ръсти", "МЫШЬ ВЗГЛЯНИТЕ", "ДЖОЙСТИК ШАБЛОН", "РЕЗОЛЮЦИЯ" и подсказки обучения, по которым сложно понять, что делать. Здесь около 4400 строк переведены заново с учётом того, где и как каждая из них показывается в игре:

- интерфейс, настройки, меню, магазин и бухгалтерия;
- всё обучение: насосы, тромель, конвейер, доводка, бурение;
- письма дедушки, записки и сюжетные подсказки;
- подсказки управления на технике.

Терминология единая: стрела, рукоять, ковш, отвал, рыхлитель, тромель, промприбор, шлюз, маты, пески, вскрыша, хвосты, доводка, буровая колонна, штанга.

Руководство в Steam: https://steamcommunity.com/sharedfiles/filedetails/?id=3843179321

## Установка

1. Скачайте архив `GroundworkRU_v1.x.zip` (последняя версия) со страницы [Releases](../../releases/latest).
2. Закройте игру.
3. Распакуйте архив и запустите `УСТАНОВИТЬ.bat`. Скрипт сам найдёт игру в библиотеке Steam, а если не найдёт, попросит путь к папке игры.
4. В игре выберите: Настройки → Общие → Язык → Русский.

Если Windows SmartScreen пишет "Windows защитила ваш компьютер", нажмите "Подробнее" → "Выполнить в любом случае".

## Удаление

Запустите `УДАЛИТЬ (вернуть оригинал).bat` или в Steam: ПКМ по игре → Свойства → Установленные файлы → Проверить целостность файлов.

## После обновления игры

Steam при обновлении заменяет `game.exe`, и перевод слетает. Просто запустите `УСТАНОВИТЬ.bat` ещё раз. Строки, которые появились в новой версии игры, останутся с переводом разработчиков, пока русификатор не обновится.

## Как это работает

Игра не читает файлы из `assets\locales`: русские строки хранятся прямо внутри `game.exe` в виде JSON-каталога. Установщик `patcher.ps1`:

1. делает резервную копию `game.exe.ru-backup`;
2. находит в `game.exe` русский каталог (по строке `"LANGUAGE": "ЯЗЫК"`);
3. подставляет строки из `ru_translation.json` и проверяет плейсхолдеры `{0}`, `{1}`...;
4. записывает каталог обратно того же размера (свободное место заполняется пробелами внутри JSON).

Больше в `game.exe` ничего не меняется. Скрипт открытый, его можно прочитать в любом текстовом редакторе.

## Исправления и предложения

### Для тех, кто хочет править перевод

Исходники перевода лежат в `source/tr/*.txt`, по одной строке на запись: `номер<TAB>перевод`. Номер соответствует порядку строки в английском каталоге игры. Плейсхолдеры можно писать как в английском (`{control0}`, `{}`, `{:.1}`) или сразу позиционно (`{0}`, `{1}`).

Сборка `ru_translation.json`:

```
cd source
python extract_catalogs.py "путь\к\game.exe"
python build.py
python variants.py
```

`variants.py` дополняет `ru_extra.json`: игра перед поиском перевода переименовывает термины в английском тексте (cleanup table → Gold Table, cleanup pallet → mat pallet, washplant → trommel и т.п.) и показывает отдельные абзацы подсказок, поэтому для них нужны отдельные ключи. Строки, добавленные вручную, лежат в `source/extra_manual.json`.

`extract_catalogs.py` достаёт английский и русский каталоги из вашего `game.exe` (нужен оригинальный, не пропатченный exe или `game.exe.ru-backup`). Сами файлы игры в репозиторий не выкладываются.

## Состав

| Файл | Назначение |
|---|---|
| `GroundworkRU/УСТАНОВИТЬ.bat` | установка |
| `GroundworkRU/УДАЛИТЬ (вернуть оригинал).bat` | возврат оригинального `game.exe` |
| `GroundworkRU/patcher.ps1` | установщик (PowerShell) |
| `GroundworkRU/ru_translation.json` | перевод: английский текст → русский |
| `GroundworkRU/ru_extra.json` | строки, которых нет в каталоге игры (например `CURRENCY`) |
| `source/` | исходники перевода и скрипты сборки |

Это фанатский перевод, он не связан с разработчиками игры.
